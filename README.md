Just a Minimal and basic New Tab Page for Chromium Based browsers, which follows the Windows 11 Fluent Design System.
Works on-
  ➡️Chrome
  ➡️Brave
  ➡️Edge
  ➡️and literally any Chromium Based browser
How to install-
  ➡️You can clone the repo and go through all the steps
  ➡️or just set the Live Demo Webpage(https://fluent-new-tab.vercel.app/) as your New tab page
P.S.- Search Engine is set to Google(for now)
