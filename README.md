Just a Minimal and basic New Tab Page for Chromium Based browsers, which follows the Windows 11 Fluent Design System.
Works on-
  •Chrome
  •Brave
  •Edge
  •and literally any Chromium Based browser
Steps to install-
  •Download the FNT.zip file and extract it
  •Go to extensions and enable Developer Mode
  •Click on Load Unpacked and open the folder created from extracting the .zip file
  •Click Select Folder and Turn on the Extension
  •Enjoy
